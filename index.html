НД ТЗК Ош

Внутренняя система нормативных документов

Служебная система ТЗК «Ош» для хранения нормативных документов, ознакомления сотрудников с ними и учёта сроков проверки оборудования.

Система предназначена только для сотрудников. Учётные записи выдаёт администратор; самостоятельная регистрация не предусмотрена.
